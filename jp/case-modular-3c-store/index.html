ANONYMOUS PROJECT / 3C RETAIL

中古3C店舗のモジュールディスプレイシステム

台北の初店舗を起点に、高額電子商品の展示、複製展開、輸送、組立の要件を整理した事例です。

PROJECT EVIDENCE

顧客の課題

MacBook Air、iPhone、iPad、iMac、カメラ、ゲーム機などを扱う中古3C店舗について、他都市にも展開できる特徴的な展示システムが求められました。

開発内容

プロジェクト記録には、矩形パイプと水平連結による壁面システム、追加ガラスショーケース、機能を変えられる交換式トップを持つ共用キャビネットが記録されています。輸送と組立のしやすさも要件でした。
