THE PROJECT NEED

Project context

The source description records a 28-room boutique hotel in central Taipei, organized around four named floor concepts across a six-level building: Idea, Notation, Reason and Type.

Design direction

The collection combines classic and modern cues, keeps the guestrooms comfortable and uses coordinated materials and furniture types to form one hospitality language.
